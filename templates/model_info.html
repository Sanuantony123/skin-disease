Convolutional Neural Network Pipeline

Two-stage transfer learning with depthwise separable convolutions

Base Extractor

MobileNetV2 pre-trained on ImageNet. Inverted residual blocks with linear bottlenecks optimized for edge inference.

Input Preprocessing

Standardized (224, 224, 3) RGB tensor mapping with internal pixel rescaling layer to avoid scaling discrepancies.

Data Augmentation

Spatial rotation, zoom, horizontal flips, and contrast jittering during training for dermatological scale invariance.

Classification Head

GlobalAveragePooling2D, Dropout (rate 0.35), followed by Dense projection with 23 softmax class outputs.

Stage 1: Head Tuning

Frozen backbone with Adam optimizer (lr = 1e-3) training the custom 23-way clinical classification layers.

Stage 2: Fine-Tuning

Unfreezing the top 30 convolutional blocks with micro learning rate (1e-5) to adapt specialized dermis features.
